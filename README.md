# What secret scanning evaluations measure — supporting evidence

Supporting evidence and reproducible arithmetic examples for the critical methodological review by Tripti Tiwari and Mohit Tiwari, prepared for submission to *Computing*.

## Contents
- `extraction_ledger.csv`: structured evidence extraction for assessed studies.
- `claim_locations.json`: source-level claim locations.
- `assessed_source_manifest.json`: assessed source manifest.
- `descriptive_appraisal.csv`: descriptive methodological appraisal.
- `discovery_queries.csv` and `Search_and_Selection.md`: discovery and selection records.
- `reference_verification_ledger.json`: reference verification information.
- `counterexample_results.json`, `tables.json`: supporting results and tabulations.
- `code/counterexamples.py`: arithmetic counterexample script.

## Reproduce
Run `python3 code/counterexamples.py` in Python 3.

## Provenance and limitations
These files reproduce the supporting evidence supplied as Online Resource 1 in the authors' submission package. Source-level judgments and retrieval status should be interpreted according to the documented extraction and selection records. The repository does not redistribute full text of third-party publications.

## Citation
Tiwari, T. and Tiwari, M. *What secret scanning evaluations measure*. Manuscript prepared for submission; do not cite as accepted or published.
